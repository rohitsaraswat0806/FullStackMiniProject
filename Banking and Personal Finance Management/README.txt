# Banking and Personal Finance Management System

Beginner-friendly college project made using only HTML and CSS.

## Team Folder Division

- Member 1: Dashboard (`index.html`) + Accounts (`accounts.html`)
- Member 2: Transactions (`transactions.html`)
- Member 3: Personal Finance (`finance.html`)
- Member 4: Transfer Money (`transfer.html`) + Profile (`profile.html`)

Each member has their own folder containing their HTML file(s) and CSS file.

## Technologies
- HTML5
- CSS3

## How to run
Open `Member 1/index.html` in a browser.

The navigation links are updated so that all pages can open across the four member folders.

Note: This is a front-end demo. It does not connect to a real bank, database, or payment system.
